# Hospital data source

`medical_clean.csv` is the hospital dataset provided for WGU D603 and described in the Medical Data Considerations and Dictionary. It supplies the classification and clustering analyses. The classification outcome is `ReAdmis`; `Initial_days` is completed length of stay, available at discharge. Repository results describe this course dataset.

The course materials reviewed identify the dataset and scenario but do not state an upstream redistribution license. The repository’s MIT license covers the project code, not a new license grant for third-party data. No claim that the records are synthetic is made.
